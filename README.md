# Backend-приложение для автоматизации закупок

Дипломный проект по профессии «Python-разработчик: расширенный курс». Разработан backend-сервис для автоматизации заказов товаров в розничных сетях на Django REST Framework.

Основной функционал:

* Полный набор REST API для управления товарами, заказами и пользователями по готовой спецификации
* Настраиваемые характеристики товаров и импорт/экспорт данных
	•	Отправка накладных и подтверждений заказов на email с использованием асинхронных задач
	•	Система управления заказами с админкой и статусами
	•	Авторизация и регистрация пользователей через API с разграничением прав доступа

-----

## Технологии и инструменты

Django REST Framework, PostgreSQL, Celery, Redis, Docker, асинхронный Python, AI-инструменты

-----

## Особенности

	•	Разделение медленных операций (email, импорт/экспорт) в фоновые задачи
	•	Полная документация API и примеры запросов
	•	Проект ведётся в публичном GitHub-репозитории с регулярными коммитами
